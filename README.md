# Sistem Pengelolaan Data Penghuni dan Transaksi Sewa Kos
 
Aplikasi web sederhana untuk membantu pengelola kos mencatat data kamar,
data penghuni, transaksi sewa, dan pembayaran, menggantikan pencatatan manual.
 
## Fitur
- Login Admin dan Penghuni
- Dashboard (jumlah kamar, kamar tersedia/terisi, jumlah penghuni)
- Data Master: Data Kamar dan Data Penghuni
- Transaksi: Transaksi Sewa (termasuk check-out) dan Pembayaran
- Laporan: Laporan Penghuni dan Laporan Pembayaran
- Penghuni dapat melihat informasi sewa dan status pembayarannya
 
## Teknologi
PHP, MySQL, dan XAMPP (server lokal saat pengembangan).
 
## Dokumen Perancangan
SRS, Use Case, Activity, Sequence, State Machine, Class, dan Object
Diagram tersimpan di folder docs/.
